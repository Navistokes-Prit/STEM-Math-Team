Test Questions

Create each question once, then drag Knowledge outcomes from the curriculum column onto the question. If a question assesses multiple outcomes, each tagged curriculum reference lists the question numbers that assess it in the Knowledge Distribution. Adding a new question automatically minimizes the questions above it.
