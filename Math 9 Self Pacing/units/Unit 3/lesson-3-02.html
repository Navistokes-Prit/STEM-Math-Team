Lesson 3.02

Collecting Like Terms

Simplify algebraic expressions by combining terms with matching variables and exponents.

Practice LevelFoundation
Quick Review

Like Terms

What Makes Terms Like?

Like terms have exactly the same variables raised to exactly the same exponents.

7x2y - 3x2y

Both terms contain x²y, so their coefficients can be combined.

Combine Coefficients

When terms are like, add or subtract only their coefficients. Keep the variable part unchanged.

2t + 9t = 11t

The variable t stays the same.

New Learning

Simplifying by Collecting Like Terms

1

Group matching variable parts.

For example, x² terms combine with x² terms, but not with x terms.

2

Combine constants separately.

Numbers without variables form their own group of like terms.

3

Write the simplified expression clearly.

A final expression should contain only one term for each distinct variable part.

Worked ExampleTwo Variables
8a + 5b - 2a + b
  1. Combine a-terms: 8a - 2a = 6a.
  2. Combine b-terms: 5b + b = 6b.
  3. Answer: 6a + 6b.
Worked ExampleVariables and Constants
5x + 2y + 4 + 8x + 4y + 3
  1. x-terms: 5x + 8x = 13x.
  2. y-terms: 2y + 4y = 6y.
  3. Constants: 4 + 3 = 7.
  4. Answer: 13x + 6y + 7.
