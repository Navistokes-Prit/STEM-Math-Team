Lesson 1.11

Adding Rational Numbers

Add fractions and mixed numbers by using common denominators and simplifying the result.

Practice Level Foundation
Quick Review

Fraction Conversion Review

Equivalent Fractions

Equivalent fractions represent the same value.

1/2 = 2/4 = 4/8

Equivalent forms help create common denominators.

Mixed and Improper Forms

Mixed numbers can be changed to improper fractions before calculating.

2 1/3 = 7/3

Multiply the whole number by the denominator, then add the numerator.

New Learning

Adding Fractions

1

Same denominator: add numerators.

Keep the denominator unchanged.

2

Different denominators: find a common denominator.

Rewrite both fractions as equivalent fractions.

3

Simplify the final answer.

Reduce the fraction and convert to a mixed number when appropriate.

Worked ExampleSame Denominator
3/8 + 2/8
  1. The denominators already match.
  2. Add the numerators: 3 + 2 = 5.
  3. 3/8 + 2/8 = 5/8.
Worked ExampleDifferent Denominators
2/3 + 1/4
  1. The least common denominator is 12.
  2. 2/3 = 8/12 and 1/4 = 3/12.
  3. 8/12 + 3/12 = 11/12.
