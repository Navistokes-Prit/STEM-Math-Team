Lesson 4.06

Scale Diagrams

Use model-to-actual ratios, map scales, and unit conversions to solve scale drawing and blueprint problems.

Practice Level Foundation
Quick Review

Scale Drawings

Scale

A scale is a ratio comparing a model or drawing with the actual object.

drawing : actual

Both quantities must be in the same units when writing a numerical ratio such as 1:r.

Representing Real Size

A statement scale tells how much actual distance each drawing unit represents.

5 cm represents 1 m

Use multiplication for drawing-to-actual and division for actual-to-drawing.

New Learning

Maps and Blueprints

1

Convert units before forming a 1:r scale.

For example, convert kilometres to centimetres before comparing with a map length in centimetres.

2

Use the scale consistently.

If 1 cm represents 20 cm, multiply every drawing length by 20 to get the actual length.

3

Check whether the question asks for drawing length or actual length.

Reverse the operation when working from the real object back to the diagram.

Worked Example Statement Scale
5 cm on a drawing represents 1 m in real life.
  1. 1 m = 100 cm.
  2. 5 : 100 simplifies to 1 : 20.
  3. The scale is 1:20.
Worked Example Map Distance
Scale 1:25,000 and map length 9.6 cm.
  1. Actual length = 9.6 × 25,000 cm.
  2. That is 240,000 cm.
  3. 240,000 cm = 2.4 km.
