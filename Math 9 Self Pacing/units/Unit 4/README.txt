GENERATED PRACTICE
------------------
The Unit 4 engine generates fresh questions client-side.

Visual geometry questions use inline SVG diagrams. This means:
- no external image files are required for generated diagrams
- diagrams remain sharp at any screen size
- GitHub Pages can serve everything statically

Practice includes:
- straight-line, point, vertical, corresponding, alternate, and co-interior angles
- triangle classification, interior/exterior angles, and congruence
- translations, reflections, and rotations
- line and rotational symmetry
- similarity and scale factor
- map and blueprint scales
- basic and composite area
- surface area of prisms
- curved/open/closed cylinder surface area

QUIZ PASSWORD
-------------
In unit-quiz.html change:

const TEACHER_PASSWORD = "CHANGE-THIS-PASSWORD";

to the password you want.

As with the earlier units, GitHub Pages is static, so this is a classroom
access barrier rather than server-side secure authentication.
