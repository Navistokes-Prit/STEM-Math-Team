Lesson 5.02

Table of Values and Plotting

Substitute values into a linear rule, organize ordered pairs in a table of values, and prepare points for plotting.

Practice Level Foundation
Quick Review

From a Rule to a Table of Values

Input and output

A table of values records ordered pairs from a relation. The x-column is the input and the y-column is the output.

For \(y=2x+1\), input \(x=3\) gives output \(y=7\).

Substitution

Replace the variable with the given value. Use brackets when substituting a negative number so the sign stays attached to the value.

If \(y=4x+2\) and \(x=-3\), then \(y=4(-3)+2=-10\).
New Learning

Build the Table

1

Choose or read the x-values.

Work one row at a time. Keep the x-values in the order given.

2

Substitute each x-value.

Write the substituted calculation before simplifying. This reduces sign errors.

3

Record the ordered pair.

Each completed row represents a point (x, y) that can be plotted on a graph.

Worked ExampleComplete one row
\(y=-2x+5,\quad x=4\)
  1. Substitute x = 4: y = −2(4) + 5.
  2. Multiply first: y = −8 + 5.
  3. So y = −3 and the point is (4, −3).
Worked ExampleNegative input
\(y=3x-1,\quad x=-2\)
  1. Use brackets: y = 3(−2) − 1.
  2. Multiply: y = −6 − 1.
  3. So y = −7 and the point is (−2, −7).
