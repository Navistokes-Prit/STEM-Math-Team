Quick Review

Coordinates, Lines, and Sequences

Reading a coordinate

An ordered pair is written (x, y). Move horizontally first to find x, then vertically to find y. A point on an axis has one coordinate equal to 0.

\((3,-2)\) means 3 units right and 2 units down.

Horizontal and vertical lines

Every point on a horizontal line has the same y-value, so its equation is y = constant. Every point on a vertical line has the same x-value, so its equation is x = constant.

Through \((0,5),(3,5),(6,5)\): \(y=5\).
New Learning

Linear Sequences

1

Find the first term.

The first term tells you where the sequence begins.

2

Find the common difference.

For a linear sequence, subtract one term from the next. The same difference repeats each time.

3

Extend the pattern carefully.

Add the common difference for an increasing sequence; add a negative difference (equivalently subtract) for a decreasing sequence.

Worked ExampleIncreasing sequence
\(15,\ 18,\ 21,\ 24,\ 27,\ldots\)
  1. The first term is 15.
  2. 18 − 15 = 3, so the common difference is +3.
  3. The next three terms are 30, 33, 36.
Worked ExampleDecreasing sequence
\(30,\ 24,\ 18,\ 12,\ldots\)
  1. The first term is 30.
  2. 24 − 30 = −6, so the common difference is −6.
  3. Continue by subtracting 6: 6, 0, −6.
