Lesson 5.08

Equation from Table of Values

Find the constant rate of change and initial value in a table, then write the linear equation that connects the variables.

Practice Level Foundation
Quick Review

Equation from a Table of Values

Find the rate of change

When x increases by 1 each row, the change in y is the slope. If x changes by more than 1, divide Δy by Δx.

\(m=\dfrac{\Delta y}{\Delta x}\).

Find the initial value

If the table contains x = 0, its y-value is b immediately. Otherwise use any row in y = mx + b and solve for b.

If \(m=3\) and \((2,11)\) is in the table: \(11=3(2)+b\), so \(b=5\).
New Learning

Write and Check the Rule

1

Confirm the change is constant.

A linear table has a constant rate of change. If the rate changes, a single equation y = mx + b will not model every row.

2

Write y = mx + b.

Insert the slope and initial value with the correct signs.

3

Test more than one row.

Substitute another x-value. The predicted y-value should match the table.

Worked Examplex increases by 1
\((0,4),(1,7),(2,10),(3,13)\)
  1. The y-values increase by 3 each time, so m = 3.
  2. At x = 0, y = 4, so b = 4.
  3. The equation is y = 3x + 4.
Worked ExampleNo x = 0 row
\((2,1),(4,5),(6,9)\)
  1. \(m=\frac{5-1}{4-2}=2\).
  2. Use (2,1): \(1=2(2)+b\), so \(b=-3\).
  3. The equation is \(y=2x-3\).
