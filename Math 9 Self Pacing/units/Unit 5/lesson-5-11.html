Lesson 5.11

Forming Linear Equations to Solve Problems

Translate a word problem into a linear equation, solve it, and interpret the answer in context.

Practice Level Foundation
Quick Review

Forming Linear Equations from Words

Define the unknown first

Choose a variable and state what it represents. This makes every later expression easier to interpret.

Let \(x\) be the original number.

Translate one phrase at a time

Words such as sum, difference, times, more than, and perimeter describe operations. Build expressions before writing the final equation.

“6 more girls than boys” becomes \(x+6\) if \(x\) is the number of boys.
New Learning

A Reliable Problem-Solving Routine

1

Read and identify the unknown.

Underline quantities and decide what one variable can represent.

2

Build an equation from the relationships.

Use the total, perimeter, age relationship, or sequence condition stated in the problem.

3

Solve, then interpret.

A numerical x-value is not the final answer until you state what it means and check that it fits the context.

Worked ExampleConsecutive integers
The sum of three consecutive integers is \(111\).
  1. Let the integers be x, x + 1, x + 2.
  2. Equation: x + (x + 1) + (x + 2) = 111.
  3. 3x + 3 = 111 → 3x = 108 → x = 36. The integers are 36, 37, 38.
Worked ExampleRectangle perimeter
A rectangle is 7 m longer than it is wide. Its perimeter is 106 m.
  1. Let width = x, so length = x + 7.
  2. 2x + 2(x + 7) = 106.
  3. 4x + 14 = 106 → x = 23. Width = 23 m and length = 30 m.
