Curriculum Reference

Math 31 curriculum sub-outcomes are numbered permanently beneath each Math 31 Sub-outcome. Drag any CU, PK, or PS sub-outcome onto a test question.

Key: CU = Conceptual Understanding  •  PK = Procedural Knowledge  •  PS = Problem-solving Context

Test Questions

Create each question once, then drag Knowledge outcomes from the curriculum column onto the question. If a question assesses multiple outcomes, each tagged curriculum reference lists the question numbers that assess it in the Curriculum Distribution. Adding a new question automatically minimizes the questions above it.
